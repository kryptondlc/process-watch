# Process Watch

Портативный диспетчер процессов для Windows 10 и 11 от **krypton.dlc**.

**[Скачать Process Watch](https://github.com/kryptondlc/process-watch/releases)**

Открой нужный релиз, разверни **Assets** и скачай файл `ProcessWatch-<версия>.exe`. Запусти его из папки, в которой хочешь хранить приложение. Установщик не нужен.

## Возможности

- Поиск и сортировка процессов по имени, PID и использованию памяти. Можно открыть расположение файла, вычислить SHA-256 или завершить выбранный процесс.
- Цветовая оценка риска на основе локальной проверки подписи и доступных записей Microsoft Defender. Зелёная метка означает подтверждённую подпись файла. Она не гарантирует безопасность.
- **Ctrl + Shift + F9** возвращает окно из трея. Можно также использовать **Win + Shift + Alt + H**, если сочетание доступно.
- **Экстренный режим** предлагает выбрать окна для обычного закрытия. Приложения могут запросить сохранение изменений.

Крестик убирает окно в трей. Чтобы полностью завершить работу, выбери **Файл → Выйти из Process Watch**.

## Обновления

Открой **Обновления → Проверить сейчас**. Источник по умолчанию в версии 1.5.2 и новее — этот репозиторий. Проверка учитывает стабильные релизы.

Если у релиза есть подходящий EXE и GitHub сообщает его SHA-256, кнопка **Скачать и установить** загрузит файл, сверит хеш, заменит текущий EXE и перезапустит программу. Для установки запусти приложение с обычными правами из папки, в которую можешь записывать файлы. В противном случае можно скачать EXE со страницы релиза и заменить его вручную после полного выхода.

## Проверка файлов

Process Watch запускает сканирование через Microsoft Defender, когда он доступен. Если Windows использует другой антивирус, можно открыть расположение файла и проверить его в этом антивирусе. Состояние поставщиков видно в **Защита → Состояние антивирусов**.

Если у релиза нет цифровой подписи, Windows SmartScreen может показать предупреждение. SHA-256 файла указан на странице релиза.
